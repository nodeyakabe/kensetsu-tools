元請から「セキュリティ対策はどうしていますか」「情報管理の体制を教えてください」と聞かれたとき、何をどう答えればよいか迷う一人親方や小さな建設会社の担当者は多いでしょう。

結論から言うと、**「パソコンにパスワードをかけている」「預かった書類は決まった場所にまとめて管理している」「不要になったら削除・廃棄している」** の3点が言えれば、小規模事業者として最低限の対応として認めてもらえるケースがほとんどです。

## 元請がセキュリティ確認をする理由

元請会社は、自社が取得した個人情報（現場作業員の名簿など）を下請けや一人親方に預けます。**個人情報保護法上、元請は委託先（一人親方など）の監督義務を負う**ため（個人情報保護法第25条）、セキュリティ対策の確認をするようになっています。

また、2024年以降、国土交通省が推進する建設キャリアアップシステム（CCUS）や「建設業における情報セキュリティガイドライン」の普及にともない、一次・二次下請けへの確認が増えています。「自社のセキュリティ対策が問われる場面が増えた」と感じているなら、こうした背景があります。

## 聞かれやすい項目と対応状況の確認

| 確認項目 | 対応例 | 優先度 |
|---|---|---|
| パソコンのパスワード・ロック | Windows PINまたはパスワードを設定 | 高 |
| ストレージの暗号化 | Windowsの「デバイスの暗号化」またはBitLockerを有効化 | 高 |
| 個人情報の置き場所の管理 | フォルダを決め、アクセスできる人を限る | 高 |
| 不要データの削除 | 現場終了後に不要な名簿・健診結果を削除またはシュレッダー | 高 |
| ウイルス対策ソフト | Windows Defenderまたはサードパーティ製 | 中 |
| OSのアップデート | 自動更新を有効にする | 中 |
| バックアップの管理 | バックアップ先も鍵のかかる場所で保管 | 中 |
| 外部サービスへの送信制限 | 個人情報を不要にクラウドへ送らない運用 | 中 |

一人親方や小規模事業者の場合、専門的なシステムや規程文書より、「今すぐ確認できる事実」として上記の項目を整理しておくことが実務的です。

## 今日からできる対策

### 1. パソコンにパスワードを設定する

Windowsの「設定 → アカウント → サインインオプション」でPINまたはパスワードを設定します。これだけでも「パスワード管理をしています」と答えられます。

### 2. デバイスの暗号化を有効にする

「設定 → プライバシーとセキュリティ → デバイスの暗号化」をオンにすると、パソコンを盗まれたときに中のデータを読まれにくくなります。BitLocker対応機種ではBitLockerも活用できます。

### 3. 個人情報の置き場所を決める

作業員名簿・健康診断の結果・免許証のコピーなどは、**専用のフォルダ1か所にまとめる**のが基本です。LINEやメール・写真フォルダに散らばった状態は、管理できているとは言えません。

### 4. 現場が終わったらデータを整理する

現場終了後、その現場のためだけに預かった個人情報は**必要な保管期間が過ぎたら削除**します（作業員名簿の保存義務期間は完成後3年間が目安）。紙の場合はシュレッダーにかけます。

### 5. 外部サービスへの送信に気をつける

無料のクラウドストレージや海外製のアプリに個人情報を保存すると、サービス側の事故で情報が流出するリスクがあります。作業員名簿などはインターネットに送らず、**パソコンの中だけで管理する**ことも選択肢です。

## 元請への回答例

確認を求められたときに、以下のように答えられると具体的です。

> 「パソコンにはパスワード（PIN）を設定し、暗号化しています。預かった書類は専用フォルダにまとめて管理し、現場が終わったら不要な個人情報は削除しています」

セキュリティの専門資格がなくても、**日常的に行っている具体的な対策**を言えることが大切です。

## 預かった個人情報について詳しく知りたい場合

作業員名簿・免許証のコピー・健康診断の結果など、建設業で預かりやすい個人情報の種類と保管のコツは「[作業員名簿・免許証コピーの保管、大丈夫？](/blog/kojin-joho-hokan/)」で詳しく解説しています。
