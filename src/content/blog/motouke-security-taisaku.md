最近、元請から「御社のセキュリティ対策について教えてください」というアンケートやチェックシートが届くようになった、という話を聞くことが増えました。背景にあるのが、国が整備を進めている**SCS評価制度（サプライチェーン強化に向けたセキュリティ対策評価制度）**です。

結論から言うと、**今すぐ★を取るよう求められる段階ではありませんが、取引先からセキュリティ対策を確認される流れは、これから確実に強まります**。一人親方や小さな会社でも、基本の対策ができているかを今のうちに点検しておくのがおすすめです。

## なぜ下請のセキュリティが問われるのか

大きな会社が直接狙われるのではなく、セキュリティの弱い取引先を足がかりにして攻撃される事例が問題になっています。取引先のパソコンやメールが乗っ取られれば、そこから元請や発注者の情報が漏れたり、システムが止まったりするおそれがあるからです。

一方で、下請の側には「取引先ごとに違うチェックシートが届いて、答えるのが大変」という負担がありました。SCS評価制度には、こうした確認の基準をそろえるねらいもあります。

## SCS評価制度とは

経済産業省が所管し、IPA（情報処理推進機構）が運営する制度です。会社や個人事業主のセキュリティ対策を★の数で評価し、発注する側は取引先に「★いくつ以上」を求められるようになります。2027年3月に★3・★4の受付が始まる予定です。

| | ★3 | ★4 |
|---|---|---|
| 想定する攻撃 | 広く知られた弱点を突く、よくある攻撃 | 供給停止や機密情報の流出につながる攻撃 |
| 求められる対策 | 基礎的な体制づくりと、パソコン・ネットワークの防御 | 体制づくり、取引先の管理、攻撃の検知、事故対応まで含む包括的な対策 |
| 評価の方法 | 自己評価（専門家の確認つき） | 評価機関による第三者評価 |
| 有効期間 | 1年 | 3年 |

★3は「サプライチェーンに関わるすべての会社が最低限そろえておくべき対策」と位置づけられています。評価は会社だけでなく、個人事業主単位でも受けられます。

なお、これは法律で全員に義務づけられる制度ではありません。取引の条件として、発注する側が取引先に求める使い方を想定した仕組みです。対策にかかる費用を価格交渉で考慮する事例も、経済産業省と公正取引委員会から示されています。

## まずは「SECURITY ACTION」から

いきなり★3を目指すのは大変、という場合の入口として、IPAは**SECURITY ACTION（セキュリティ対策自己宣言）**から始めることを勧めています。中小企業や個人事業主が、自分でセキュリティ対策に取り組むことを宣言する無料の制度です。

- **一つ星**：「情報セキュリティ5か条」に取り組むことを宣言する
- **二つ星**：自社の状況を診断し、基本方針を定めて宣言する

一つ星の「情報セキュリティ5か条」は、次の5つです。

1. OSやソフトウェアは常に最新の状態にしよう
2. ウイルス対策ソフトを導入しよう
3. パスワードを強化しよう
4. 共有設定を見直そう
5. 脅威や攻撃の手口を知ろう

元請からのチェックシートで聞かれることの多くは、この5か条の延長線上にあります。

## 一人親方・小さな会社がよく聞かれること

取引先からの確認では、次のような項目がよく並びます。

| 聞かれること | 具体的には |
|---|---|
| パソコンの更新 | WindowsやOfficeの更新を止めずに当てているか |
| ウイルス対策 | ウイルス対策ソフト（Windows標準のものを含む）が有効になっているか |
| パスワード | 使い回していないか、推測されやすくないか。メールなどで2段階認証を使っているか |
| バックアップ | 大事なデータのバックアップをとっているか |
| 共有の設定 | クラウドの共有リンクやフォルダを、関係ない人まで見られる設定にしていないか |
| 個人情報の扱い | 作業員名簿や健康診断の結果など、預かった個人情報をどう管理しているか |
| 事故のときの連絡 | 乗っ取りや情報漏えいに気づいたら、誰にどう連絡するか決めているか |

## 今日からできる基本対策

チェックシートに「はい」と答えられるように、まずは次のことを確認しておきましょう。

- Windowsの更新を「一時停止」にしたままにしていない
- ウイルス対策が有効になっている（Windowsのセキュリティ画面で確認できます）
- メールやクラウドのパスワードを使い回していない。2段階認証が使えるものは設定する
- 大事なデータは、パソコン以外の場所にもバックアップをとっている
- 預かった作業員の個人情報の置き場所を決めている
- 乗っ取りや紛失に気づいたときの連絡先（元請の担当者など）を控えている

完璧を目指すより、「聞かれたときに、何をしているか説明できる」状態にしておくことが大切です。

## 元請への回答例

確認を求められたときに、以下のように答えられると具体的です。

> 「パソコンにはパスワード（PIN）を設定し、暗号化しています。預かった書類は専用フォルダにまとめて管理し、現場が終わったら不要な個人情報は削除しています」

セキュリティの専門資格がなくても、**日常的に行っている具体的な対策**を言えることが大切です。

## 預かった個人情報の扱いも見られる

チェック項目のなかでも、建設業で特に気をつけたいのが、作業員名簿や健康診断の結果、免許証のコピーといった**預かった個人情報の扱い**です。保管のコツは「[作業員名簿・免許証コピーの保管](/blog/kojin-joho-hokan/)」で詳しく解説しています。
