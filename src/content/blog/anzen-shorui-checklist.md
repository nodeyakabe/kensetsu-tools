元請に出した安全書類（グリーンファイル）が「ここが違います」と差し戻されて、現場入りが遅れた——一人親方からよく聞く話です。結論から言うと、**差し戻しの原因の大半は「期限切れ」と「記入漏れ」**です。書類そのものの書き方より、出す前の確認でほとんど防げます。

この記事では、一人親方がよく求められる書類と、提出前に確認したい項目をチェックリストにまとめます。

## 一人親方がよく求められる書類

元請や現場によって違いますが、一人親方が求められることが多いのは次の書類です。

| 書類 | 内容 |
|---|---|
| 作業員名簿 | 自分の氏名・生年月日・資格・健康診断・保険・緊急連絡先など |
| 再下請負通知書（事業者情報） | 屋号・住所・許可の有無など、自分の事業者としての情報 |
| 契約書類 | 契約書、または約款付きの注文書・請書 |
| 一人親方労災保険の特別加入証明書 | 一人親方として労災に特別加入していることの証明 |
| 建設業退職金共済の証紙交付辞退届 | 建退共の証紙を受け取らない場合に出す書類 |
| 資格証の写し | 技能講習・特別教育の修了証、免許証など |
| 持込機械等使用届・工事・通勤用車両届 | 機械や車両を現場に持ち込む場合 |

このほか、元請から健康診断の結果や、社会保険の加入状況がわかる書類を求められることもあります。グリーンサイトを使う現場では、これらをサイト上で登録・提出します。

## 提出前チェックリスト

書類を出す前に、次の項目を確認してください。

### 期限

- [ ] 一人親方労災保険の特別加入が、**今年度分に更新されているか**（加入証明書の年度を確認）
- [ ] 健康診断が**直近1年以内**に受けたものか
- [ ] 運転免許証など、**有効期限のある免許**が切れていないか
- [ ] 持ち込む重機の**特定自主検査（年次）や車検**が期限内か
- [ ] 前の現場の書類を使い回すとき、日付や工期が今回の現場になっているか

### 記入

- [ ] 作業員名簿の**社会保険欄**を正しく選んでいるか（一人親方は一般に、健康保険は国民健康保険または建設国保、年金は国民年金、雇用保険は適用除外）
- [ ] 資格欄に、**実際に持っている資格をすべて**書いているか（現場で使う作業の資格が漏れていないか）
- [ ] 緊急連絡先・血液型などの空欄がないか
- [ ] 持込機械の届けで、**点検表を1台ずつ**埋めているか
- [ ] 元請が指定する**様式**を使っているか

### 添付

- [ ] 資格証・免許証のコピーが**鮮明**で、文字が読めるか
- [ ] 特別加入証明書など、求められた証明書類をそろえたか

## よくある差し戻しの理由

特に多いのは次の3つです。

**1. 労災特別加入や健康診断の期限切れ**
一人親方労災保険の特別加入は年度ごとに更新します。更新手続きをしていても、新しい年度の証明書を出し忘れて差し戻されることがあります。健康診断も、受診から1年を超えていると受け付けられないことがほとんどです。健康診断の種類や頻度は「[建設業の健康診断は義務？](/blog/kenshin-obligation/)」で整理しています。

**2. 社会保険欄の選び間違い**
作業員名簿の社会保険欄は、雇われている人と一人親方で書き方が違います。会社員向けの欄（健康保険組合、厚生年金など）を選んでしまうと差し戻されます。一人親方として加入している保険を選びましょう。作業員名簿全体の書き方は「[作業員名簿の書き方と、元請け提出でつまずかないコツ](/blog/sagyoin-meibo/)」をご覧ください。

**3. 資格証のコピーが読めない**
スマートフォンで撮った写真が暗い、ピントが合っていない、修了証が古くてかすれている、といった理由で確認できないケースです。読めない場合は撮り直すか、発行元に再発行を申し込みましょう。なお、技能講習や特別教育の修了証そのものには、法律上の有効期限はありません（詳しくは「[技能講習・特別教育の修了証に有効期限はある？](/blog/qualification-expiry/)」）。

## 差し戻しを防ぐコツは「期限の一覧」を持つこと

チェックリストの多くは、**いつ何が切れるか**を把握していれば防げるものです。労災の更新時期、健康診断の受診日、免許や重機の検査期限。これらを書類を出すたびに調べ直すのではなく、一覧にして手元に持っておけば、提出前の確認は数分で終わります。

機械を持ち込む場合の届けについては「持込機械等使用届とは？電動工具でも必要？」、グリーンサイトでの登録の流れは「[一人親方がグリーンサイトで求められる資格・書類まとめ](/blog/hitori-oyakata-greensite/)」もあわせてご覧ください。

> 本記事は一般的な実務の解説です。求められる書類や様式は元請・現場によって異なるため、最終的には元請の指示に従ってください。
