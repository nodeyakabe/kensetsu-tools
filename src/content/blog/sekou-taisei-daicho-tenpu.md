元請けから「施工体制台帳に入れるので、書類を出してください」と言われて、何を出せばいいのか迷ったことはありませんか。施工体制台帳そのものを作るのは元請けですが、**下請や一人親方にも、台帳に載せる情報や添付する書類の提出が求められます**。この記事では、施工体制台帳とは何か、どんな書類が添付されるのか、下請側は何を準備しておけばいいのかを整理します。

## 施工体制台帳とは

施工体制台帳は、その工事に**どの会社（人）が、どんな契約で、どんな体制で関わっているか**をまとめた台帳です。建設業法で、一定の工事では元請けに作成が義務づけられています。

| 項目 | 内容 |
|------|------|
| 作る人 | 発注者から直接工事を請け負った元請け（作成建設業者） |
| 載る人 | その工事に関わるすべての下請（建設業の許可がない業者も含む） |
| 置く場所 | 工事現場ごとに備え置く |
| 保存 | 工事の目的物を引き渡してから5年間（帳簿の添付資料として） |

## 作成が必要になる工事

| 工事の種類 | 作成が必要になる場合 |
|-----------|--------------------|
| 公共工事 | 下請契約を結んだら、金額にかかわらず必要 |
| 民間工事 | 特定建設業の元請けが結ぶ下請契約の総額が **5,000万円以上**（建築一式工事は **8,000万円以上**） |

民間工事の金額は、**2025年（令和7年）2月1日の改正で引き上げられました**（それまでは4,500万円、建築一式工事は7,000万円）。この下請契約の総額には、資材の納入・調査・運搬・警備などの契約は含めません。

> 公共工事では、作成した台帳の写しを発注者に提出することも義務づけられています。

## 主な記載事項と添付書類

### 主な記載事項

- 元請け・下請それぞれの会社名、建設業の許可（特定・一般の別）
- 健康保険・年金・雇用保険の加入状況
- 工事の内容と工期
- 主任技術者・監理技術者の氏名と資格
- 現場で働く人の情報（いわゆる作業員名簿。資格、安全衛生教育、建退共・中退共の加入の有無など）
- 外国人技能実習生などが従事しているかどうか

作業員名簿は、2020年の省令改正で**施工体制台帳の一部として作成する**ことになりました。様式は決まっていないため、元請けごとに書式が違うことがあります。

### 添付書類

| 添付書類 | 中身 |
|---------|------|
| 発注者との契約書の写し | 元請けと発注者の契約 |
| 下請負人との契約書の写し | 注文書・請書と、基本契約書または基本契約約款など |
| 技術者の資格を証明する書面 | 元請けが置く主任技術者・監理技術者の資格証の写し（専任の監理技術者は監理技術者資格者証の写し） |
| 専門技術者の資格を証明する書面 | 専門技術者を置いた場合 |
| 技術者の雇用関係を証明する書面 | 健康保険証の写しなど |

このうち、**下請側から出すことになるのは主に「下請負人との契約書の写し」**です。民間工事では、元請けが当事者でない下請契約の金額は消して出せますが、公共工事ではすべての下請契約の金額が書かれていなければなりません。

## 下請・一人親方は何を出すのか

### 再下請をしない場合

自分が請けた工事を、さらに別の業者に出さない（自分で施工する）場合、**再下請負通知書を出す義務はありません**。ただし、作業員名簿に載せる自分の情報（資格・健康診断・保険の加入状況・緊急連絡先など）は、元請けから求められるのが普通です。

### 再下請をする場合

一次下請以降が、請けた工事の一部をさらに別の業者に出すときは、**再下請負通知書**を元請け（作成建設業者）に出します。再下請負通知書には、**再下請負人との契約書の写し（注文書・請書と基本契約約款など）**を添付します。提出は遅滞なく、原則は元請けに直接です。

| 自分の立場 | 主に求められるもの |
|-----------|------------------|
| 一次下請（再下請なし） | 元請けとの契約書の写し、作業員名簿の情報 |
| 一次下請（再下請あり） | 上に加えて、再下請負通知書と再下請負人との契約書の写し |
| 二次以降の下請・一人親方 | 作業員名簿の情報。さらに下に出すなら再下請負通知書 |

> 元請けによっては、グリーンサイトなどのWebサービスで提出を求められます。登録に必要な書類は「[一人親方がグリーンサイトで求められる資格・必要書類まとめ](/blog/hitori-oyakata-greensite/)」で整理しています。

## 施工体系図との違い

施工体系図は、施工体制台帳の**要約版**です。下請の会社名や技術者を樹状の図にまとめ、工事現場の見やすいところに掲示します。公共工事では、工事関係者だけでなく**公衆が見やすい場所**（道路に面した場所など）にも掲示します。図に載るのは、その時点で実際に施工している下請です。

## 下請側でつまずきやすいところ

**① 契約書が手元にない**
口約束や電話だけで仕事を受けていると、添付する契約書の写しが出せません。注文書・請書を交わす習慣をつけておきましょう。

**② 作業員名簿の情報が古い**
資格の取得日、健康診断の受診日、労災特別加入の期間などが古いまま出すと、差し戻しの原因になります。書き方は「[作業員名簿の書き方と、元請け提出でつまずかないコツ](/blog/sagyoin-meibo/)」、提出前の確認は「[安全書類の提出前チェックリスト](/blog/anzen-shorui-checklist/)」も参考にしてください。

**③ 保険欄の書き方に迷う**
作業員名簿の保険欄には、加入している保険の名称（例：国民健康保険、国民年金）を書きます。事業主であるなどで雇用保険の適用除外にあたる場合は「適用除外」と書きます。一人親方としての書き方に迷ったら、元請けに確認しましょう。

## まとめ

施工体制台帳を作るのは元請けですが、その中身は**下請から集めた情報と書類**でできています。下請・一人親方が普段から整えておきたいのは、**契約書（注文書・請書）の写し**と、**作業員名簿に載せる自分の情報（資格・健康診断・保険）**の2つです。特に資格や健康診断、労災特別加入には期限があるので、[資格・健康診断・労災保険の期限をまとめて管理できる「シンプル安全台帳」](/products/anzen-daicho/)のような台帳で一覧にしておくと、元請けから求められたときにすぐ出せます。
